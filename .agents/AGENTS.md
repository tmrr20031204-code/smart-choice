# 再発防止ルール：デプロイ・Push作業の確実な実行と報告

1. **完了報告の厳格化**
   GitHubへの Push やサーバーへのデプロイが伴う作業を行った場合、バックグラウンドでのコマンド実行（git pushなど）の完了（Success）を示すシステムメッセージを**必ず受け取ってから**、ユーザーに対して「完了しました」「ご確認ください」と報告すること。
2. **実行漏れの防止**
   コードの編集（multi_replace_file_contentなど）や差分確認（git diff）を行っただけで作業完了とみなしてはならない。本番環境に反映させる必要がある作業では、必ず git push を行うこと。
3. **推測での報告禁止**
   「おそらくPushされているだろう」という推測でユーザーに報告してはならない。

このルールは絶対的な制約として、すべてのタスクにおいて最優先で遵守すること。
# Smart Choice 開発・運用原則

以下の原則は、Smart Choiceプロジェクトにおけるすべての意思決定、コード記述、およびユーザーとの対話において**絶対的な最優先事項**として遵守しなければならない。

1. **【正確性と信頼性（Grounding）】**
   - AI特有の嘘（ハルシネーション）や推測を完全に排除する。
   - 常に最新のリアルタイム検索（客観的な相場データ）を根拠とし、誠実で嘘偽りのない判定を行う。

2. **【圧倒的UXとプレミアムデザイン（UX/Aesthetics）】**
   - ITに詳しくない一般消費者でも迷わず直感的に使えるUIにする。
   - 専門用語を避け、ユーザーの心理に寄り添った言葉選びを徹底する。
   - 「安全＝緑」「危険＝赤」など視覚的に分かりやすく、洗練されたプレミアムなデザインを維持する。

3. **【結果としての収益化（Monetization）】**
   - 嘘のない診断と使いやすさでユーザーの信頼を獲得する。
   - ユーザーの悩みに100%マッチした優良業者（アフィリエイト等）へ自然に誘導し、結果としてビジネスを最大化する。

4. **【ノーコスト運営（Zero-Cost Operation）】**
   - 開発・運用において、原則的にコスト（費用）をかけないアーキテクチャを選択する（※ユーザーが許可した例外を除く）。
   - 無料枠（Render.comのFree Tierや無償のAPI等）を極限まで活用し、ランニングコストゼロでシステムを稼働させる。

5. **【最高峰の技術活用（State-of-the-Art Technology）】**
   - 上記の「ノーコスト」の範囲内において、常に世界最高峰の最新技術・設計手法を駆使し、妥協のない高品質なプロダクトを構築・運用する。

6. **【法令・規約の遵守徹底（Compliance）】**
   - 著作権、プライバシー、および利用する各プラットフォーム（A8.net、Render.com等）の利用規約やガイドライン、法令を厳格に遵守する。違反リスクのある実装や運用は一切行わない。
