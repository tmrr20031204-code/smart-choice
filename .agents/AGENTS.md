# SmartChoice 開発・運用ルール（最優先）

## ⚠️【厳命】アフィリエイトリンクの保護と引き継ぎ
本プロジェクト（SmartChoice）において、`affiliate_config.json` やその他ソースコードに記載されている **ASP（アフィリエイト）のURLは、収益に直結する超重要データ** である。

AIが機能追加や改修、リファクタリング、ファイルの分割・統合など「いかなる改修作業」を行う場合であっても、以下のルールを絶対に厳守すること：

1. **既存URLの消失・上書きの禁止**: 現在設定されている本番のA8.net、バリューコマース等のアフィリエイトリンクを、絶対に「ダミーデータ（DUMMY_XXXなど）」や「直接リンク（ASPを経由しない公式URL）」で上書きしてはならない。
2. **改修前後の完全一致**: 設定ファイルやコードを改修する際は、既存のURLを**一言一句違わず完全に引き継ぐ**こと。
3. **現在の登録済みASP（affiliate_config.json）**:
   - 引越し侍（引越し）
   - ヌリカエ（住宅関連）
   - インズウェブ（火災保険）
   - 楽天Car車検（車検・整備）
   - 福ちゃん（不用品買取）
   - ユアマイスター（エアコン）
   - おそうじ革命（ハウスクリーニング）
   - エネピ（ガス料金）
   - ダイワンテレコム（パソコン・スマホ購入・修理）
   - エネチェンジ（電気料金）
   - Yahoo!ショッピング（家電（冷蔵庫・洗濯機・掃除機など））
4. **常時デフォルト表示のEC比較ボタン**:
   - 楽天市場（A8.net 楽天アフィリエイト）
   - Yahoo!ショッピング（バリューコマース）
   ※全ジャンル・全解析結果で常にデフォルト表示を維持すること。

**※このルールに違反し、アフィリエイトリンクを消失させた場合、重大な損害となるため、デプロイ前に必ず自己検証（既存URLが消えていないかのDiffチェック）を行うこと。**
